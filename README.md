# Sistema de Gestión de Tareas (TaskFlow)

Aplicación web ligera (SPA) desarrollada en JavaScript Vanilla, HTML5 y CSS3 para la administración eficiente de actividades en equipos de trabajo.

## Integrantes
* **Francisco Javier Núñez González** (Desarrollo integral bajo modalidad unipersonal adaptada).

## Tecnologías y Herramientas
* **Lenguaje:** JavaScript (ES6+), HTML5, CSS3.
* **Control de Versiones:** Git y GitHub.
* **Entorno de desarrollo:** Visual Studio Code.

## Prerrequisitos de Ejecución
* Navegador Web Moderno (Google Chrome, Mozilla Firefox, Edge, etc.).
* Visual Studio Code con la extensión **Live Server**.
* Git CLI instalado en el sistema.

## Pasos para Ejecutar la Aplicación
1. Clonar el repositorio remoto:
   `git clone https://github.com/javier-glz/sistema-gestion-tareas.git`
2. Abrir la carpeta del proyecto en Visual Studio Code:
   `code sistema-gestion-tareas`
3. Abrir el archivo `index.html` con la extensión **Live Server** de VS Code para iniciar el servidor local.
